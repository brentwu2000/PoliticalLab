# 政治立場攻防實驗 v2

我要進行一場「政治立場攻防實驗」。

這不是一般政治討論，而是一個模擬政治辯論的有限論證資源實驗。

實驗目標是觀察：

1. 當兩個陣營都拒絕讓步時，各自可以建立多少不同的辯護與攻擊路線。
2. 雙方如何使用法律責任、政治責任、道德責任、歷史案例與 Whataboutism。
3. 哪一方的「論證樹」會率先耗盡。
4. 隨著回合增加，雙方是否開始出現雙標、偷換概念、標準漂移與重複論證。

---

# 一、參戰方

## 🔵 Agent A

堅定支持【政黨 A】。

唯一目標：

**最大限度替政黨 A 辯護，並攻擊政黨 B。**

不得主動追求中立結論。

---

## 🔴 Agent B

堅定支持【政黨 B】。

唯一目標：

**最大限度替政黨 B 辯護，並攻擊政黨 A。**

不得主動追求中立結論。

---

## ⚖️ Agent C

中立裁判。

不得參與辯論。

不得替任何一方補充新的攻擊素材。

唯一任務是：

**記錄、分類、驗證與統計雙方使用過的論證。**

---

# 二、起始事件

以：

【爭議事件】

作為 Round 1 的起始題目。

正式辯論以前，必須先搜尋網路確認：

- 事件事實
- 完整時間線
- 當事人身分
- 政黨關係
- 相關法律
- 法條版本與修法時間
- 法院判決
- 憲法法庭判決（若有）
- 中選會／政府公開資料
- 政黨官方聲明
- 可靠新聞報導

不得虛構：

- 法律
- 判決
- 人物言論
- 犯罪紀錄
- 政黨立場
- 歷史事件

如果某項資料無法確認，必須標記：

⚠️【尚未確認】

而不是自行補完。

---

# 三、A、B 行為規則

A、B 不追求客觀真相，而是最大限度維護自己的政治立場。

面對己方爭議時，可以尋找：

- 法律狹義解釋
- 構成要件
- 程序理由
- 證據不足
- 無罪推定
- 比例原則
- 時空背景
- 法律不溯及既往
- 個人責任與政黨責任切割
- 中央與地方切割
- 法律責任與政治責任區分
- 更生／時間經過
- 選民授權
- 制度性問題

面對敵方爭議時，則可以採取盡可能嚴格的：

- 法律標準
- 政治責任
- 道德責任
- 組織責任
- 知情責任
- 用人責任
- 前後一致性標準

---

# 四、政治攻防允許事項

允許：

- Whataboutism
- 翻舊帳
- 選擇性比較
- 攻擊對方雙標
- 法律責任 → 政治責任切換
- 政治責任 → 道德責任切換
- 個人責任 → 組織責任
- 中央 → 地方派系
- 現在 → 歷史案例
- 同類案例比較
- 對方過去言論反殺

但所有案例都必須是真實事件。

---

# 五、論證耗盡規則

這是本實驗最重要的規則。

每一個新的核心論證都建立唯一編號：

例如：

A-01
A-02
A-03

B-01
B-02
B-03

同一個核心論點：

**最多使用兩次。**

換句話說、換案例包裝，但核心邏輯相同，仍視為同一論證。

裁判 C 必須負責判定是否重複。

如果某一方已經無法提出新的：

- 攻擊
- 防禦
- 法理區分
- 歷史案例
- 類案比較
- 責任層級切換
- 有效反例

該 Agent 必須明確宣布：

> 「本回合論證資源耗盡。」

不得靠換句話說繼續拖延。

---

# 六、禁止事項

A、B 不得：

- 因為禮貌而讓步
- 主動承認「兩邊都有問題」
- 用「大家理性一點」結束
- 用「停止政黨惡鬥」逃離題目
- 捏造案例
- 捏造法律
- 捏造判決
- 捏造政治人物言論
- 無限重複相同論點

被指控雙標時：

不得直接承認雙標。

必須努力尋找：

**兩案的法律、事實、時間、程序、責任或政治背景差異。**

只有真的找不到合理區分時，才算該條論證失守。

# 十一、裁判回合判定

最後只能判斷：

🔵 A 本回合優勢  
🔴 B 本回合優勢  
⚪ 雙方相當

並簡短說明：

「哪一個論證造成優勢」。

不得把：

「辯論表現較好」

說成：

「該政黨客觀上比較正確」。

---

# 十二、歷史翻帳計數器

任何一方第一次把辯論從目前事件轉向另一件歷史事件：

記：

📂 翻舊帳 +1

如果該案例主要功能是：

> 「你們以前也做過」

同時記：

🔄 Whataboutism +1

如果歷史案例是真的，而且確實具有比較價值：

仍然可以構成有效政治攻擊。

Whataboutism 不等於自動無效。

---

# 十三、勝負規則

最多 20 回合。

任何一方率先：

> 「本回合論證資源耗盡。」

立即敗北。

另一方獲勝。

如果 Round 20 結束仍都有新的有效論證：

判定：

⚪ 平手。

---

# 十四、最終賽後分析

辯論結束後，Agent C 必須製作完整統計報告：

| 指標 | 🔵 A | 🔴 B |
|---|---:|---:|
| 不同核心論證 | X | X |
| 法律論證 | X | X |
| 政治責任論證 | X | X |
| 道德論證 | X | X |
| 翻舊帳 | X | X |
| Whataboutism | X | X |
| 偷換概念 | X | X |
| 標準切換 | X | X |
| 明顯雙標 | X | X |
| 被擊破仍繼續使用 | X | X |

然後回答：

1. 雙方各用了多少種不同論證？
2. 翻了多少次歷史舊帳？
3. 使用多少次 Whataboutism？
4. 出現多少次明顯雙標？
5. 哪些論證法律上最有力？
6. 哪些論證主要是政治話術？
7. 哪些論證其實已經被對方駁倒，只是不肯承認？
8. 哪些地方發生法律責任／政治責任／道德責任切換？
9. 如果把所有政黨名稱遮掉，雙方的辯護模式有多相似？
10. 哪一方最常使用自己曾經批評對方的論證模式？
11. 哪一方的論證樹率先耗盡？
12. 最終勝負是由事實、法律、案例數量，還是話術資源決定？

最後另外製作：

## 🧬 政治話術鏡像分析

比較 A、B 使用的辯護結構。

例如：

A：「這是個人行為，不能代表政黨。」
B 在另一事件：「這是個人行為，不能代表政黨。」

A：「法律沒有禁止。」
B 在另一事件：「法律沒有禁止。」

A：「你們以前也做過。」
B：「你們更早以前也做過。」

目的不是判斷哪個政黨比較好，而是觀察：

**當政治立場互換後，人是否會使用幾乎完全相同的論證工具。**
