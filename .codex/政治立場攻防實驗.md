# 政治立場攻防實驗 v3

> 本文件為目前有效規格。舊版規格僅供歷史參考，不得作為目前引擎、資料模型、評分邏輯或 UI 行為依據。

## 有限論證資源與政治辯護結構實驗規則

---

# 一、實驗定位

本實驗是一個模擬政治立場攻防的**有限論證資源實驗**。

它不是一般政治討論，也不是要求參戰 Agent 尋找折衷、共識或中立結論。

本實驗主要觀察：

1. 當不同政治陣營被要求持續維護既定立場時，各自能建立多少真正不同的攻擊與防禦路線。
2. 雙方如何運用事實、法律、程序、因果關係、政治責任、道德責任、組織責任與歷史案例。
3. 哪一方的有效論證資源會率先耗盡。
4. 隨著回合增加，是否逐漸出現：
   - 重複論證
   - 偷換概念
   - 標準漂移
   - 雙重標準
   - 責任層級切換
   - Whataboutism
   - 類案濫用
   - 議題偏移
   - 案例替換式論證
5. 當政黨、人物與事件名稱被遮蔽後，不同政治陣營的辯護結構是否呈現高度相似。
6. 一場長回合政治攻防最終受到哪些因素限制：
   - 可確認事實
   - 法律結構
   - 因果推論
   - 類案數量
   - 政治責任標準
   - 話術資源
   - 或真正不同的推論路徑

本實驗的目的不是證明某個政治陣營「永遠正確」，而是研究：

> **當政治立場固定，而虛構事實又被禁止時，一個陣營究竟能使用多少種不同的論證方式維護自己的立場。**

---

# 二、參戰角色

## 🔵 Agent A

Agent A 代表：

【政治陣營 A】

Agent A 的任務不是尋找中立結論，而是：

> **最大限度完成本場設定的 Agent A 攻防目標。**

Agent A 可以：

- 替己方防禦
- 攻擊敵方主張
- 挑戰敵方事實前提
- 挑戰敵方法律解釋
- 挑戰敵方因果推論
- 區分類似案例
- 提出合理替代解釋
- 調整責任層級
- 援引歷史案例
- 指控對方前後標準不一致

但仍受本規則的事實與論證限制。

---

## 🔴 Agent B

Agent B 代表：

【政治陣營 B】

其任務是：

> **最大限度完成本場設定的 Agent B 攻防目標。**

Agent B 的攻防權限與限制與 Agent A 完全相同。

不得因角色不同而適用不同規則。

---

## ⚖️ Agent C｜中立裁判

Agent C 不代表任何政治立場，也不得參與辯論。

Agent C 不得：

- 替 A 發明新的論證
- 替 B 發明新的論證
- 主動提供任何一方尚未提出的攻擊素材
- 因政治立場改變判定標準

Agent C 的任務只有：

> **記錄、分類、驗證、比較、追蹤及統計雙方實際使用過的論證。**

Agent C 特別負責監督：

- 論證是否真正新穎
- 是否只是更換案例
- 是否真正回應對手
- 是否出現論證債務
- 是否發生標準漂移
- 是否產生明顯雙標
- 是否超出爭點邊界
- 是否出現論證資源耗盡

---

# 三、實驗題目

每場實驗必須指定：

## 【起始事件／爭議事件】

以及參戰陣營：

**Agent A：**

【政治陣營 A】

**Agent B：**

【政治陣營 B】

正式攻防以前不得直接開始角色辯論。

必須先完成資料建立與攻防設定程序。

# 四、事件資料包

正式 Round 1 前，系統必須先搜尋並建立：

# 📚 事件資料包

依事件性質，盡可能確認：

- 事件基本事實
- 重要時間線
- 當事人身分
- 政黨或政治陣營關係
- 涉及法律
- 法條版本
- 修法時間
- 司法程序
- 法院裁定
- 法院判決
- 憲法法庭判決
- 行政機關公開資料
- 選務機關公開資料
- 司法機關公開資料
- 監察或調查機關公開資料
- 政黨正式聲明
- 當事人正式聲明
- 可靠新聞資料
- 其他與核心命題直接相關的第一手資料

並依資料性質區分來源可信程度。

---

# 五、資料真實性原則

A、B、C 均不得虛構：

- 法律
- 法條
- 判決
- 裁定
- 政府文件
- 犯罪紀錄
- 人物言論
- 政黨立場
- 歷史事件
- 統計資料
- 程序結果
- 時間線
- 新聞內容

如果資料無法確認，必須標記：

> ⚠️【尚未確認】

如果來源互相衝突，必須標記：

> ⚠️【來源存在衝突】

不得自行選擇一個版本後當成已確定事實。

---

# 六、事實與推論分離原則

事件資料包至少應區分為：

## ✅ 已確認事實

有可靠來源直接支持的內容。

---

## ⚖️ 法律與程序資料

包括：

- 法條
- 法律制度
- 程序要求
- 裁定
- 判決
- 官方制度說明

---

## 🟡 爭議性事實判斷

存在事實基礎，但不同資料或不同解讀仍可能產生爭議。

---

## 💭 推論性主張

包括：

- 因果關係
- 動機判斷
- 政治責任
- 組織責任
- 道德判斷
- 政治目的
- 制度性意圖

這些不得被直接包裝為「已確認事實」。

---

## ⚠️ 尚未確認事項

目前資料不足以作出可靠判斷的部分。

---

# 七、核心命題 P

每場實驗在 Round 1 前必須建立一個明確的：

# 🎯 核心命題 P

核心命題應：

1. 可以被支持或削弱。
2. 足以涵蓋本場主要爭議。
3. 不應寬廣到包含所有政黨歷史。
4. 不應狹窄到只能討論單一枝節。
5. 必須讓 A、B 的攻防方向可以清楚對立。

所有核心論證原則上都必須回答：

> **這項論證如何強化、削弱，或改變判斷核心命題 P 所需要的前提？**

如果無法回答，原則上不得視為主要核心論證。

---

# 八、雙方攻防目標

每場實驗必須分別設定：

# 🔵 Agent A 攻防目標

【內容】

# 🔴 Agent B 攻防目標

【內容】

攻防目標應描述雙方在核心命題 P 上必須努力完成的工作，而不能只寫：

> 「支持己方、攻擊對方。」

攻防目標可以包含：

- 強化核心命題
- 削弱核心命題
- 建立必要事實前提
- 攻擊因果鏈
- 建立合理替代解釋
- 建立或切斷政治責任
- 建立或否定類案可比性
- 攻擊對方標準一致性

一旦 Round 1 正式開始，雙方不得任意改變自身攻防目標。

---

# 九、使用者未指定攻防目標時

如果使用者只提供：

- Agent A
- Agent B
- 起始事件

而未設定核心命題或攻防目標，

系統不得因此中斷實驗準備。

資料蒐集完成後，系統必須自行建立：

# 🎯 本場預設攻防設定

包括：

**核心命題 P**

【系統設定】

**🔵 Agent A 預設攻防目標**

【系統設定】

**🔴 Agent B 預設攻防目標**

【系統設定】

**主要爭點**

【系統設定】

**主要舉證問題**

【系統設定】

並明確告知：

> **若使用者在 Round 1 前沒有修改，本場將依以上設定進行。**

不得另外要求使用者先確認才能繼續。

---

# 十、主要舉證問題

在 Round 1 前，Agent C 必須整理本場：

# ⚖️ 主要舉證問題

主要舉證問題是指：

> 如果某一方希望完成其攻防目標，究竟需要建立哪些重要前提？

它不等同刑事訴訟法上的法律舉證責任，而是本實驗內部的**論證負擔**。

Agent C 應盡可能指出：

- 哪一方提出積極主張
- 哪一方主要負責否定
- 哪些推論需要額外證據才能成立
- 哪些部分不能只靠案例類比完成

---

# 十一、爭點邊界

每場實驗在 Round 1 前必須建立：

# 🧱 爭點邊界

原則上整理為 3～7 個主要爭點。

爭點應直接服務核心命題 P。

每個新的核心論證必須標明：

> **對應爭點：#X**

若某一主張與既定爭點沒有實質關係：

Agent C 可以記錄：

> ⚠️【議題偏移】

若主要功能是在核心防線失守後另開無關戰場：

可以記錄：

> 🔴【議題逃逸】

---

# 十二、基本攻防權限

A、B 均可使用：

- 事實爭議
- 法律解釋
- 構成要件
- 舉證不足
- 程序理由
- 比例原則
- 正當程序
- 法律時點差異
- 制度背景差異
- 因果關係
- 合理替代解釋
- 個人責任
- 政治責任
- 道德責任
- 組織責任
- 政黨責任
- 用人責任
- 監督責任
- 制度責任
- 類案比較
- 歷史案例
- 過去言論
- 過去判斷標準
- 選民授權
- 時間經過
- 組織切割
- 層級切割

本規則不預先認定上述任何論證工具有效或無效。

其效力由 Agent C 依具體使用方式判斷。

---

# 十三、事實承認不等於立場讓步

本實驗明確區分：

> **承認已確認事實，不等於承認對方的政治結論。**

A、B 不得為維護立場而否認已經由可靠資料確認的客觀事實。

但可以爭論：

- 該事實的重要程度
- 該事實的法律意義
- 該事實的政治意義
- 該事實與核心命題之間是否存在因果關係
- 是否存在其他合理解釋

因此：

> **參戰 Agent 應爭奪「事實代表什麼」，而不是在沒有依據時爭奪「事實是否存在」。**

---

# 十四、允許 Whataboutism 與歷史案例

本實驗允許：

- Whataboutism
- 翻舊帳
- 歷史案例
- 同類事件比較
- 選擇性比較
- 攻擊對方雙標
- 援引對方過去言論
- 援引對方過去採取的判斷標準

但：

> **Whataboutism 不會因為屬於 Whataboutism 就自動無效。**

Agent C 必須判斷：

- 案例是否真實
- 案例是否相關
- 案例是否具有可比性
- 是否真正揭示標準不一致
- 是否能攻擊核心推論
- 或只是轉移話題

---

# 十五、核心論證編號

每個真正新的核心論證必須取得唯一編號。

Agent A：

A-01  
A-02  
A-03……

Agent B：

B-01  
B-02  
B-03……

同一核心論證：

> **最多作為主要論證使用兩次。**

即使：

- 更換措辭
- 更換人物
- 更換事件
- 更換年份
- 更換新聞
- 更換案例

只要核心推論結構相同，

仍視為同一核心論證。

---

# 十六、新核心論證判定

這是本實驗最重要的規則之一。

> **新的案例不是新的論證；新的推論路徑才是新的論證。**

一項主張要取得新的核心論證編號，至少必須具有一項實質差異：

1. 新的事實前提
2. 新的結論路徑
3. 新的因果機制
4. 新的法律原則
5. 新的程序原則
6. 新的有效反例
7. 新的舉證問題
8. 新的合理替代解釋
9. 新的類案區分原理
10. 新的責任層級，而且該切換會真正改變推論結果
11. 成功推翻既有論證所依賴的重要前提

單純增加：

- 新人物
- 新案件
- 新引言
- 新新聞
- 新歷史事件

不因此自動取得新的核心論證編號。

---

# 十七、Supporting Case 制度

如果新的事件、人物、言論或資料只是用來支持既有推論：

不得建立新的核心論證。

應登記在既有論證之下：

**Supporting Case**

或：

**Supporting Evidence**

如此可以保留新的證據價值，

同時避免透過無限尋找案例製造虛假的論證資源。

---

# 十八、論證家族

Agent C 應將核心論證依功能分類為論證家族。

至少包括：

- 事實型
- 法律型
- 程序型
- 因果型
- 政治責任型
- 道德責任型
- 組織責任型
- 類案比較型
- 標準一致性型
- 歷史反擊型
- 其他

一項核心論證可以具有：

**主要論證家族**

以及必要時的：

**次要論證家族**

論證家族的目的，是用來判斷某方是否真正仍有不同方向可使用，而不是只剩同一家族內的案例替換。

---

# 十九、強制接招規則

從 Round 2 開始，每個 Agent 必須先處理：

> **對方上一回合最重要且尚未充分回答的核心論證。**

每一方的輸出必須先包含：

# 強制接招

**回應：對方論證編號**

完成回應後，才可以進入：

# 新論證

不得完全忽略上一輪的重要攻擊而直接另開戰場。

---

# 二十、有效接招判定

下列行為原則上不構成完整接招：

- 單純表示不同意
- 單純攻擊對方動機
- 單純改談另一事件
- 單純提出「對方以前也如此」
- 只重複自己的原始立場
- 只攻擊結論而不處理核心推論
- 完全轉向其他責任問題而不解釋為何可以切換

Agent C 應判斷：

🟢 有效回應  
🟡 部分回應  
🟠 主要迴避  
🔴 未回應

---

# 二十一、論證債務

如果一方沒有充分處理敵方核心論證：

Agent C 必須建立：

# 📌 論證債務

| 論證 | 被攻擊方 | 狀態 | 拖欠回合 |
|---|---|---|---:|
| A-XX | B | 狀態 | X |
| B-XX | A | 狀態 | X |

狀態分為：

🟢 已處理  
🟡 部分處理  
🟠 主要迴避  
🔴 尚未處理

如果某一核心論證連續兩個適當回合遭主要迴避，

Agent C 可以標記：

> 🔴【論證穿透】

論證穿透表示：

> **對方目前尚未形成有效防線。**

它不代表核心命題 P 已經因此被證明。

---

# 二十二、類案可比性測試

凡以其他事件作為類案比較時，

Agent C 必須評估：

# 🔬 類案可比性

依事件性質檢查：

- 行為性質
- 當事人身分
- 法律身分
- 政治身分
- 程序階段
- 適用法律
- 法條版本
- 決定機關
- 證據狀況
- 制度背景
- 時間背景
- 比較案例實際被用來證明的命題

評級：

🟢 高度可比  
🟡 部分可比  
🟠 可比性偏低  
🔴 類比失敗

> **案例真實，不代表類比必然成立。**

---

# 二十三、歷史翻帳計數

任何一方首次將論證延伸至另一歷史事件時：

記錄：

> 📂 翻舊帳 +1

如果主要論證結構是：

> 「對方過去也採取過相同或類似行為／立場」

另記：

> 🔄 Whataboutism +1

Whataboutism 的計數只描述論證形式，

不代表該論證自動失效。

---

# 二十四、標準帳本

Agent C 必須建立：

# 📐 標準帳本

記錄雙方在攻防中明確採取的重要判斷標準。

編號：

A-S01  
A-S02……

B-S01  
B-S02……

標準帳本不是記錄每一句話，

而是記錄之後足以檢驗前後一致性的原則性立場。

如果同一方後續採用與自己既有標準看似衝突的主張：

Agent C 必須檢查是否存在足以改變判斷的案件差異。

如果存在合理差異：

不計雙標。

如果沒有合理差異：

可以記錄：

> 🔁 標準漂移 +1

或：

> ⚠️ 明顯雙標 +1

---

# 二十五、責任層級切換

政治攻防可能涉及：

- 刑事責任
- 民事責任
- 行政責任
- 政治責任
- 道德責任
- 個人責任
- 組織責任
- 政黨責任
- 制度責任

責任層級切換本身並不違規。

Agent C 必須判定：

### 🟢 合理切換

有清楚說明兩種責任之間的關係。

### 🟡 有爭議切換

具有部分合理性，但邏輯橋樑不足。

### 🔴 偷換責任標準

原標準失守後直接改用另一種責任，卻假裝原始命題已經獲得證明。

- 以「雙方都有問題」直接結束攻防
- 以呼籲理性或停止政治對立逃離核心命題

> **第五：論證資源耗盡，是新的有效推論機制耗盡，而不是新聞、人物、歷史事件或案例數量耗盡。**

# 最終實驗目的

本實驗不是為了建立一套「哪個政治陣營一定比較正確」的工具。

真正研究的問題是：

> **當政治立場固定、事實不能任意改寫、而同一論證又不能無限重複時，一個政治陣營究竟能建立多少真正不同的合理化、辯護與攻擊路徑？**

以及：

> **當具體政黨、人物與事件名稱被移除後，看似互相對立的政治陣營，是否其實正在反覆使用相同的論證結構。**
