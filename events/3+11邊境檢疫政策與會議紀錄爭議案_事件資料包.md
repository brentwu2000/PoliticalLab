## 3. 相關法律與法條版本

1. **《傳染病防治法》第 37 條第 1 項第 6 款**：地方政府與指揮中心實施防疫管制措施授權。
2. **《傳染病防治法》第 58 條**：入境檢疫與居家檢疫措施規定。
3. **《中央流行疫情指揮中心實施要點》**：指揮官綜理指揮中心全般事務與跨部會協調決策權限。
4. **《政府資訊公開法》第 6 條與第 7 條**：行政機關決策資訊公開與紀錄保存規範。

## 4. 政黨官方聲明與立場

### 🔵 藍營/綠營攻防立場 ( Agent A vs Agent B )
- **🔵 Agent A (民進黨立場)**：
  - 強調防疫決策由專業團隊面報指揮官決定，「3+11」符合當時外站防護零接觸管理。
  - 行政院專案報告與監察院調查均證實決策「有所本」，無事證證明為社區大爆發之因果破口。
  - 范雲立委僅係履行民代職責召開協調會轉達陳情，並無介入指揮中心最終決策。
  - 呼籲停止將傳染病流行進行政治仇恨動員與抹黑。

- **🔴 Agent B (國民黨立場)**：
  - 抨擊「3+11」係民進黨立委范雲施壓、陳時中拍板之政治妥協，直接導致 2021 年社區大爆發。
  - 痛批衛福部提不出正式專家會議紀錄，係違反政府公開透明與黑箱甩鍋。
  - 質疑行政院與監察院調查報告「官官相護」、卸責護航，不敢追究政務官政治責任。
  - 要求民進黨與陳時中為 3+11 造成上萬名國人確診與逝世正式道歉與負起政治責任。
