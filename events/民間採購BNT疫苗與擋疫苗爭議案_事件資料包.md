## 3. 相關法律與法條版本

1. **《藥事法》第 48 條之 2**：緊急使用授權（EUA）專案進口核准條款。
2. **《傳染病防治法》第 27 條與第 51 條**：國家疫苗整備、緊急採購與指揮中心統籌處置授權。
3. **《藥物樣品贈品管理辦法》第 2 條與第 14 條**：專案進口藥品與贈品申請審查規範。
4. **《國家賠償法》與國際藥害救濟免責條款（Indemnification）**：預採購與緊急授權疫苗之國家承擔法律責任機制。

## 4. 政黨官方聲明與立場

### 🔵 藍營/綠營攻防立場 ( Agent A vs Agent B )
- **🔵 Agent A (民進黨立場)**：
  - 政府絕不可能阻擋疫苗引進，反而是傾國家之力全力協助鴻海、台積電、慈濟克服藥害國家免責與國際四方合約障礙。
  - 要求原廠授權書與製造證明係衛福部為確保疫苗品質、安全與防範假疫苗之法定職責；標籤彈性處理展現實用主義。
  - 2021年初 500 萬劑 BNT 談判觸礁係因中共地緣政治打壓與上海復星獨家代理條款，非政府主動阻擋。
  - 公開與鴻海往來電郵證實蔡英文總統全力促成，所謂「大小姐阻擋」與「李大維傳話」係選舉期間之政治抹黑與扭曲。

- **🔴 Agent B (國民黨立場)**：
  - 綠營政府意識形態凌駕國人生命健康，堅持不透過大中華區代理上海復星，致使 2021 年初 500 萬劑 BNT 談判破局。
  - 指揮中心陸續拋出「看得到吃不到」、「買疫苗非買菜」、「八項條件／原廠授權書門檻」、「中國分裝質疑」等系列話術與技術性障礙，拖延民間緊急救援。
  - 質疑政府刻意壓制 BNT 疫苗進口，係為了替尚未完成三期臨床試驗的高端疫苗清空市場空間與護航 EUA。
  - 郭台銘爆料李大維傳話「大小姐說你還是不要買了」及慈濟警示「不要找麻煩」，暴露黨政高層黑箱阻擋民間捐贈事實。
