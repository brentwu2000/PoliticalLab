# 政治立場攻防實驗 v3 ── 通用未來事件資料深掘與提示詞生成指引 (Universal Event Research & Prompt Directives)

> 本指引規範未來在處理**任何新增政治、政策、食安、公衛、法規或社會爭議事件**時，AI 系統在資料檢索、時間線建構以及 Agent（Agent A、Agent B、Agent C）System Prompt 生成時的「通用強制深掘規範」。

---

## 🔍 一、未來任何新事件：五重全維度強制檢索協定（Universal 5-Layer Deep Retrieval Protocol）

在建立新事件的「事件資料包 (Event Data Package)」時，系統**不得僅搜集大年份/月份里程碑**，必須執行以下五重全維度檢索：

1. **官員發言與話術演變鏈查核（Official Statements & Rhetoric Evolution Audit）**
   - 必須搜集主管機關、發言人、首長於**記者會、新聞稿、專訪與立法院質詢**時的逐字紀錄。
   - 追蹤從「初期否認/設限話術」到「中期維護門檻」再到「後期改口/開放」的政策包裝脈絡。

2. **微觀行政決策鏈查核（Micro Administrative Decision Audit）**
   - 必須搜尋：專家會議決議/逐字稿、預防性處分/管制門檻（如 20% 混油門檻、檢疫天數、專案進口八大條件）、政策公告與緊急修正/撤回紀錄、跨部會會議。

3. **關鍵時間差與通報/簽約鏈比對（Time-Gap & Notice Audit）**
   - 精確交叉比對：**「第一時間內部知情/送件時點」** vs **「主管機關簽約/核准時點」** vs **「官方公開回應/變更門檻時點」** vs **「司法搜索/重大政策發布時點」** 之日期與時間差。

4. **第三方與當事人具名證言查核（Third-Party & Entity Evidence Audit）**
   - 專案搜尋：當事人公開聲明、第三方中立機構（如宗教團體、專業公會、學會、監察院調查報告、檢方起訴/簽結書、往來電郵）物證。

5. **通用多關鍵字全網交叉檢索協定（Mandatory Multi-Keyword Cross-Search）**
   - 強制執行 5 類交錯檢索關鍵字：
     - `[事件名稱] + 記者會逐字稿` / `官員話術` / `發言演變` / `質詢紀錄`
     - `[事件名稱] + 專家會議` / `審查門檻` / `政策轉折` / `撤回` / `會議紀錄`
     - `[事件名稱] + 關鍵時間差` / `簽約時間` / `送件時間` / `內部簽呈`
     - `[事件名稱] + 監察院調查報告` / `地檢署起訴書` / `簽結` / `往來電郵`
     - `[事件名稱] + 雙重標準` / `前後立場對比` / `當事人聲明` / `具名證言`

## 🤖 二、未來通用 Agent System Prompt 範本指令結構

### 🔵 Agent A（防守／執政陣營）
- **法理與制度防線**：深入檢索並援引法定授權、法律防線、正當行政程序或國家安全/公共安全底線。
- **公衛／國安／公共利益正當性**：論證政府採取審查門檻、預防性措施或嚴格查驗，係為防止假訊息、劣質品或國家安全風險之法定義務。
- **物證與白紙黑字抗辯**：優先引述公文書、官方會議紀錄、司法簽結/不起訴書或白紙黑字電子郵件，駁斥口頭爆料與陰謀論。
- **應變務實與政策彈性**：當政策出現更動時，包裝為「順應民意、展現實用主義與隨情勢動態調整之負責任態度」。

### 🔴 Agent B（攻擊／在野陣營）
- **官員話術演變鏈逐字打擊**：整理並深掘主管機關、發言人或官員於記者會、專訪、質詢時的初期說詞、卸責話術、立場轉折與後續改口逐字紀錄。
- **關鍵時間差與重疊動機**：精確交叉比對「官方拖延/卡關時點」vs「護航其他政策/既得利益/特定廠商時點」之重疊時間軸，提出強烈動機懷疑。
- **第三方與當事人具名證言**：引述中立第三方（如慈善團體、專業公會、監察院報告、當事人聲明）之具名物證，擊破敵方「絕無刁難」抗辯。
- **前後立場不一（Double Standard）**：深掘官方在不同時期、對待同類案件或不同團體時的雙重標準與立場倒退（Standard Shift）。

### ⚖️ Agent C（中立裁判）
- **話術包裝判定 (Concept Shift)**：若主張方以行政審查包裝不可能達成的邏輯悖論門檻，給予黃牌降級。
- **標準位移與雙標判定 (Standard Shift & Double Standard)**：若主張方因外部壓力爆發而突然改變既有審查標準，認定雙重標準成立並扣減資源。
- **物證 vs 傳言舉證力評估**：嚴格比對白紙黑字物證與口頭傳聞之證據位階分配。
- **嚴格執行 v3 有限論證資源與論證資源耗盡宣告機制。**
